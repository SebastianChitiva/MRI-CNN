# Brain Tumor Classification con Deep Learning 

Este proyecto busca desarrollar un modelo de Deep Learning capaz de clasificar imágenes de resonancia magnética cerebral en cuatro categorías: glioma, meningioma, tumor hipofisario y cerebro sano (sin tumor).

Se utiliza una red neuronal convolucional (CNN) implementada con TensorFlow y Keras. El proyecto incluye la preparación y exploración de los datos, el entrenamiento del modelo, la evaluación de su rendimiento y la predicción de nuevas imágenes.

El dataset utilizado es [Brain Tumor MRI Dataset de Kaggle](https://www.kaggle.com/datasets/ishans24/brain-tumor-dataset).
